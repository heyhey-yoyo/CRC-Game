# 已知限制

## 内容规模

- 当前只有一个病例和三条受约束路径。
- 尚未实现 GDD 计划中的六章教学战役、多病灶、完整克隆树、机制实验室和模组系统。
- 生态地图是代表性解释界面，不是 48×32 packet 模拟的完整可视化。

## 模型

- 模拟是方向性教育模型，没有使用真实剂量、实验室单位、RECIST 尺寸或患者级参数。
- 同种子反事实只说明同一模型规则下的差异，不构成治疗比较证据。
- 固定种子可重复，但没有实现跨未来主要版本的长期数值兼容保证。
- 当前模型没有独立 DC、NK、Treg 和髓系 packet；相关机制为隐藏或汇总变量。

## 临床与科学审阅

- 内容依据公开资料整理，但尚未获得具名临床专家签署或正式同行评审。
- 医学基线会过期；公开部署后应建立定期复核和内容版本公告。
- 真实指南、标签、适应证和安全信息可能变化，游戏不应作为最新临床信息入口。

## 工程验证

- 自动浏览器 smoke test使用 Chromium；Firefox、Safari 和真实移动设备仍需手工验证。
- 容器环境无法完成真实 Cloudflare 预览域名的 HTTPS、CDN、响应头和 Service Worker 网络验证。
- 没有账号、云存档或跨设备同步。
- 没有遥测；因此线上性能、错误率和完成率默认不可观测。
- 当前单病例规模无需 WebGL；Canvas 和 Worker 性能还不能代表完整产品规模。
