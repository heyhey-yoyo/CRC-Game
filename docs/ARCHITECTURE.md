# 架构说明

## 1. 运行边界

本项目是纯静态站点。Cloudflare Pages 负责分发；病例模拟、存档、报告和反事实比较全部在用户浏览器中完成。当前没有 Pages Functions、Worker API、D1、KV、R2、账号或服务端日志。

## 2. 分层

### 内容层

`data/` 中的 JSON 是医学和玩法内容的唯一公开来源。`content-manifest.json` 记录 app、内容和医学基线版本。`scripts/validate-content.mjs` 在构建前验证所需路径、病例、检测和证据结构。

### 模拟层

`js/sim-engine.js` 是确定性、可测试的纯逻辑模块。`js/sim-worker.js` 在 Web Worker 中运行它；浏览器不支持 Worker 或 Worker 创建失败时，UI 会降级到同一引擎的主线程调用。

- 隐藏时间步长：6 小时
- 玩家暂停节点：W0、W2、W4、W6、W8
- 固定种子：用于可重复教学结果和同种子反事实
- 输出：方向性疾病控制、生态风险、治疗可持续性和证据不确定性

这些数值是游戏校准值，不具备患者级临床预测意义。

### 状态与存档层

`js/storage.js` 提供：

1. IndexedDB 主存储；
2. localStorage 降级；
3. 受限环境下的内存会话降级；
4. schema 迁移；
5. 稳定 checksum；
6. 导入和导出。

### 展示层

`js/app.js` 负责状态编排、可访问对话框、键盘地图、事件流、视图切换和 PWA 更新提示。桌面采用严格行优先网格，窄屏按 A→F 顺序堆叠。

### 离线层

`sw.js` 预缓存应用壳和当前内容包。导航采用 network-first；静态资源使用 cache-first。跨域请求和非 GET 请求不进入缓存逻辑。

## 3. 安全边界

- 无用户 HTML 模板执行；所有动态文字经转义后插入。
- CSP 禁止第三方脚本、对象、嵌入框架和任意表单提交。
- 无密钥、API Token、Cookie 或个人健康数据。
- 导入存档被视为不可信输入，先校验 envelope 和 schema，再进入状态白名单清洗。
- 外部参考资料只在用户主动点击时访问。

## 4. 发布边界

`v1.0.0 Public Preview` 表示工程可公开部署，不表示内容已达到 GDD 中六章教学战役的完整规模。正式扩展病例时必须保持内容校验、固定种子测试和医学审阅流程。
